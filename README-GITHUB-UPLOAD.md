# Publicação do BlazarLab V1.3.17

1. Faça backup da versão existente do repositório público.
2. Extraia `blazarlab-public-v1.3.17-lapidada.zip`.
3. Copie o conteúdo da pasta `blazarlab_v1.3.17/` para a raiz do repositório público, mantendo `index.html` na raiz.
4. Publique na branch e pasta configuradas em GitHub Pages.
5. Após a publicação, teste tema claro/escuro, menu móvel, navegação só com teclado, tabelas acessíveis, heatmaps, zoom, tela cheia e exportação PNG.

Os testes automatizados são verificações estruturais e funcionais básicas, não uma certificação WCAG. Recomenda-se testar também em um navegador real e com leitores de tela.
