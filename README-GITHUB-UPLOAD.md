# Publicação do BlazarLab V1.3.16

1. Faça backup da versão existente do repositório público.
2. Extraia `blazarlab_v1.3.16_export-png-tema.zip`.
3. Copie o conteúdo da pasta `blazarlab_v1.3.16/` para a raiz do repositório público, mantendo `index.html` na raiz.
4. Publique na branch e pasta configuradas em GitHub Pages.
5. Após a publicação, teste tema claro/escuro, menu no celular, navegação só com teclado, tabelas dos gráficos, heatmaps, tela cheia e PNG.

A validação automatizada local não é uma certificação WCAG. Recomenda-se testar em Safari iOS/VoiceOver, Chrome/Android/TalkBack e navegador de desktop com leitor de tela.
